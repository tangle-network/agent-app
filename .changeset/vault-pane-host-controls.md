VaultPane accepts `label`, `emptyState`, `canCreate`, `canDelete` and `fileActions`, so a host can name its file collection, show a document-pane prompt, hide create or delete for sources that cannot perform them, and put product controls such as Edit in the open file's path row. Refresh and New file use icons. The chat template loads shared compiled styles before its own utilities so container and responsive variants win the cascade.
