The `@tangle-network/sandbox-ui` peer range accepts 0.128, so apps can install sandbox-ui 0.128.1. It adds `PdfViewer`, `FileList`, `FileCard` and `MessageAuthor`, and it is the first MIT-licensed release. 0.128 removes nothing agent-app imports. Development, tests and the chat template run against 0.128.1.
