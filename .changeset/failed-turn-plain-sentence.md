A failed sandbox turn no longer shows the person the harness's own failure text (its error, the refused tool, the list of every tool, a repeated-call report or a stack). `createSandboxChatProducer` puts one plain sentence in the streamed text, the stored assistant row, the error notice and the error event: "That answer stopped before it finished. Please send your question again.", or the product's `failedTurnText` (also accepted by `runDetachedTurn`). A partial answer already streamed is kept, with only the sentence after it. The withheld error event drops the detail fields that carry text (`supportDetails`, `hint`, `failureNote`), and every failure code is unchanged. The server keeps the real reason: the producer's `log` (`console.warn` when unset) receives it as `failureClass: 'runtime_failure'` with the code and any turn, session and execution ids, logged once, and the route's `onTurnComplete` `failureReason`, `onTurnError` data and turn-timing failure text read the original event, which rides under a Symbol key that JSON drops from the wire and the turn buffer.

Tool parts never carry the harness's list of every tool, live or stored: the `invalid` repair tool reads "That tool isn't available.", and any other `Available tools:` tail is cut. A model fallback's notice names both models without quoting the upstream's reason.

These keep their own words: a provider reset, a refused model key and a Router budget or balance refusal, which read as plain sentences without the harness wrapper; a refusal that would fail the same way again, which keeps its code (`MODEL_REFUSED`, `model_policy_denied` when the policy admits no model in the chain, `PAYMENT_REQUIRED`, and the protected lane's `grant_model_unsupported`, `grant_activation_missing` and `profile_unsupported`); and a funding, billing or admission refusal with HTTP status 402 or one the client's recovery UI reads (`getChatFundingRecovery`: `insufficient_credits`, `paid_access_required`, `funding_required`, or the words "insufficient credits" or "inference requires verified paid access"). Turn-health and journey scoring recognise the new sentence as a failure. `getChatFundingRecovery` moves to the browser-safe `web` module and is still exported from `web-react`.
