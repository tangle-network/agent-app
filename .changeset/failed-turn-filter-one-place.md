Every event `createSandboxChatProducer` yields now leaves through one person-facing filter, so no failure reason or tool list reaches a client by any path. A harness warning, a raw harness error, a failed `status` or `done`, and a `session.run.failed` read the failed-turn sentence like the terminal error, with the reason logged once at warn and kept for the route's hooks; a withheld warning adds no notice. A raw harness tool event, a recovered assistant row and a live tool part never carry the list of every tool, while a completed tool's output (a document it read) and every tool input stay whole. A funding, billing, admission or policy refusal keeps its own words without the harness wrapper (its `execution failed:` prefix, a tool list and an exit status), and a plainly worded failure no longer puts its raw text in `details.raw`. With `redactValues`, the route's failure hooks still receive the real reason, redacted. A protected turn whose settlement fails after its full answer keeps the answer with no failure notice and logs the failure. A closed-set `reason` code on a failure event stays as it is.
