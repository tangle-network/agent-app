# API access browser proof

The screenshots and video show the shared panel embedded in GTM with synthetic API responses.
The fixture key is not a credential.
This proves component interaction and layout, not deployed authentication.

The browser checked finite expiry, scope selection, create, masked copy, keyboard dismissal, list, revoke, and error states.
The desktop viewport was 1365 × 1050; mobile was 390 × 844.
Light and dark themes passed without horizontal overflow or page errors.
